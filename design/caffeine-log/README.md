# Handoff: カフェイン摂取ログ アプリ（モバイル 4画面）

対象リポジトリ: `moganbo0817/caffeineIntakeHistory` (branch `main`)
スタック: Next.js (App Router) / TypeScript / Tailwind CSS / localStorage / Vercel / PWA

## 概要
カフェイン摂取を2タップで記録し、「今日の総摂取量」と「いま体内に残っている推定量（半減期5時間の指数減衰）」を主役に据えたモバイル向けUI。
リポジトリの `CLAUDE.md` の機能要件と `TODO.md` のフェーズ構成に対応する画面設計です。

## このバンドルのファイルについて
同梱の HTML は **デザインリファレンス（プロトタイプ）** です。見た目と挙動の意図を示すもので、そのまま本番コードにコピーするものではありません。
実装タスクは、この HTML デザインを **リポジトリの環境（Next.js App Router + TypeScript + Tailwind）で、そのプロジェクトの規約に沿って再現すること** です。HTML/インラインスタイルは Tailwind クラス（下記トークン対応表）に置き換えてください。

## Fidelity
**High-fidelity（hifi）** — 配色・タイポ・余白・角丸は確定値です。ピクセル単位で再現してください。
ただし以下は未設計（下部「未設計・要相談」参照）：今日の飲み物別内訳、履歴の飲み物フィルター、上限警告の強調状態、設定画面、PWAアイコン。

## インタラクション・挙動
- 記録追加 → 今日の総摂取量・プログレスバー・体内残量・カーブ・履歴が即時更新（`useIntakeRecords` → `useNow` の再計算）。
- 体内残量は `useNow`（60秒間隔で十分）で再計算。カーブの現在位置マーカーも同じ時計に従う。
- カーブは 06:00〜翌02:00 を等間隔サンプリング（5分刻み程度）した折れ線。摂取イベントで立ち上がり、それ以外は `mg * 0.5^(Δt/5h)` で減衰。
- プログレスバーの色変化: `< 上限` → `#E8913F` / `>= 上限` → `#D2603F`（警告表示のトリガーもここ）。
- クイック追加チップ = 直近利用頻度上位2件をワンタップ登録（確認なし、直後にアンドゥを出すのが望ましい）。
- トランジション: シートの出入りは 240ms `cubic-bezier(.2,.8,.2,1)`、色・幅の変化は 180ms ease-out。
- レスポンシブ: モバイル1カラム固定。600px以上ではコンテンツ幅を 420px にして中央寄せ（内部レイアウトは変えない）。

## 状態
- `records: IntakeRecord[]`（localStorage、全期間保持。表示は直近7日のみ）
- `settings: { dailyLimitMg: number /* 既定400 */, bedtime: string /* "23:00" */ }`
- `draft: { presetId?: string, amountMg: number, size: 'S'|'M'|'L', at: Date }`
- 派生値: `todayTotalMg`, `residualMg(now)`, `curvePoints[]`, `peak {time, mg}`, `bedtimeResidualMg`, `lastCupBy`（上限/就寝から逆算したカットオフ時刻）, `quickAddCandidates[]`
- 半減期は定数 `HALF_LIFE_HOURS = 5`。
