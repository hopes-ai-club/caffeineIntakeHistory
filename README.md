# カフェイン摂取ログ

日々のカフェイン摂取を記録し、今日の総摂取量や体内の推定残存量を確認するためのWebアプリです。

記録と設定はブラウザの `localStorage` に保存します。サーバーやデータベースは使用しません。

## 主な使用技術

- Next.js（App Router）
- React
- TypeScript
- Tailwind CSS
- npm

## 前提環境

ローカルでの開発には、以下が必要です。

- Git
- Node.js 20.9.0以上
- npm
- JavaScriptと `localStorage` を利用できるWebブラウザ

使用中のバージョンは、次のコマンドで確認できます。

```bash
node --version
npm --version
```

### Node.jsのバージョン管理

このプロジェクトでは、特定のNode.jsバージョン管理ツールを必須としていません。複数のプロジェクトで異なるNode.jsバージョンを使用する場合は、Volta、nvm、fnmなどの利用を推奨します。

このリポジトリには `.nvmrc`、`.node-version`、Volta設定はありません。利用するツールの公式ドキュメントに従い、Node.js 20.9.0以上を選択してください。

## セットアップ

1. リポジトリをクローンし、プロジェクトディレクトリへ移動します。

   ```bash
   git clone https://github.com/hopes-ai-club/caffeineIntakeHistory.git
   cd caffeineIntakeHistory
   ```

2. Node.jsのバージョンが要件を満たしていることを確認します。

   ```bash
   node --version
   npm --version
   ```

3. ロックファイルに基づいて依存関係をインストールします。

   ```bash
   npm ci
   ```

4. 開発サーバーを起動します。

   ```bash
   npm run dev
   ```

5. ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

開発サーバーを終了するには、起動したターミナルで `Ctrl+C` を押してください。

現時点では、環境変数や `.env` ファイルの準備は不要です。

## 開発上の注意事項

- 要件、仕様、開発方針の正本は [`CLAUDE.md`](./CLAUDE.md) です。変更前に確認してください。
- カフェイン量はmg単位で扱います。
- 摂取日時は保存時にUTCのISO 8601文字列を使用し、日付の表示、入力、集計には端末のローカルタイムゾーンを使用します。
- 記録と設定はブラウザの `localStorage` に保存されます。ブラウザ、端末、プロトコル、ホスト名、ポートが変わると同じデータは共有されません。
- ブラウザのサイトデータやストレージを消去すると、保存した記録と設定が失われる可能性があります。
- 体内の残存量などは固定条件に基づく推定値です。本アプリは医学的な効果や安全性を保証するものではありません。

## トラブルシューティング

### Node.jsのバージョンが要件を満たしていない

`node --version` を実行し、20.9.0以上であることを確認してください。要件を満たしていない場合は、Node.jsまたは任意のバージョン管理ツールの公式手順に従って対応バージョンを導入してください。

### 3000番ポートが使用中になっている

先に起動している開発サーバーがあれば、そのターミナルで `Ctrl+C` を押して終了してください。別のポートを使用する場合は、例えば次のコマンドで3001番ポートを指定できます。

```bash
npm run dev -- -p 3001
```

この場合は、ブラウザで [http://localhost:3001](http://localhost:3001) を開いてください。ポートが変わると `localStorage` の保存先も別になります。

### `npm ci` が失敗する

最初にNode.jsとnpmのバージョン、および表示されたエラーメッセージを確認してください。また、npmレジストリへ接続できるネットワーク環境であることを確認してから再実行してください。

`npm ci` は `package-lock.json` と `package.json` の整合性も検証します。これらのファイルを自己判断で書き換えず、整合性に関するエラーが続く場合はプロジェクトの管理者へ相談してください。

### `npm run dev` で起動しない

依存関係のインストールが完了していること、Node.jsが20.9.0以上であること、利用するポートが空いていることを確認してください。解決しない場合は、ターミナルに表示されたエラーメッセージを添えてプロジェクトの管理者へ相談してください。

### 表示される記録や設定が想定と異なる

表示内容は、現在のブラウザとオリジンに保存されている `localStorage` のデータに依存します。別のブラウザ、端末、またはポートで開いていないか確認してください。

ブラウザのサイトデータを消去すると初期状態を確認できますが、保存済みの記録と設定は失われます。必要なデータがないことを確認してから実施してください。
